QUIZ MASTER
===========
Files:
- index.html: complete working quiz game in one file.

How to run:
1. Download and extract Quiz_Master.zip, or open index.html directly.
2. Double-click index.html to open it in Chrome, Edge, or Firefox.
3. Choose HTML, CSS, JavaScript, or Mixed Quiz.
4. Choose the time per question and number of questions.
5. Click Start quiz.

Features:
- Category-wise question bank
- Countdown timer per question
- Reset quiz button
- Skip and next buttons
- Score, progress bar, answer feedback, and final results
- Responsive layout for mobile and desktop

No installation or internet connection is required.
